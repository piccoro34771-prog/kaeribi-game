# KAERIBI v5.2 — アニメーション・遮蔽実装規則

## 主人公の固定仕様
冬服・赤いマフラー・無表情。効果線、汗マーク、頭上記号を加えない。素材は強い方向固定光源なしで作る。影はゲーム側で描く。

## スプライト規格
ソースのアトラスは1コマ136×164px、足元アンカー(68,162)。描画サイズ80×96px。4方向の行順は down, left, right, up。各方向の移動8コマ、調査4コマの元画像を保持。
正確なフレーム名・順序は `assets/hero_motion_manifest_v52.json` を参照。

## 動作のつなぎ
- 待機→歩き出し: 0→1→2、約150ms
- 歩行・走行: 0→2→1→3→0→4→1→5。脚を揃える中間姿勢を必ず挟む。
- 歩行→停止: 2→1→0、約160ms
- 調査: 0→1→2（保持）→1→0
- 放置: 8秒後から稀に軽い重心移動。大げさな記号を出さない。

## 衝突時
アニメの移動位相は実際の移動距離だけで進行させる。壁で止まったら歩行フレームを進めない。微小移動による連続した開始・停止には約105msの猶予を設ける。方向は入力だけではなく実際の移動方向から求める。

## 手前・奥の描画順
一枚絵の住宅街から屋根部分をポリゴンでクリップして主人公の後に描く。屋根への進入は禁止する。マップを増やす際は地面・高さを持つ物体・前景の屋根/塀を独立した画像に分離する。
